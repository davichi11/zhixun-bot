# @zhixun/shared-types

跨应用共享的类型与常量（平台枚举、流水线步骤名等）。

## 什么时候放这里

- 前后端都要用的**稳定契约**（平台枚举、状态码）
- 将来 CLI / SDK / 浏览器插件也要复用
- 手写维护成本低、变更频率低

## 什么时候不放这里

- 只被前端消费的 API 类型 → 用 `apps/frontend/src/types/api.ts`（自动生成）
- 只被后端使用的领域模型 → 留在后端 `src/zhixun/` 内

## 为什么不直接从后端生成一切

自动生成解决的是"**接口格式同步**"问题；本包解决的是"**跨方共享的语义约定**"问题。
把两者混在一起，会导致前端被后端的内部实现细节绑架。
