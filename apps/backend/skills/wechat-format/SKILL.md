# 公众号排版规范

## 什么时候用

稿件写完、审校通过、准备推送到公众号时。

## 排版规则

### 标题层级
- 每篇**只有一个 H1**（就是文章标题）
- H2 用于主要章节，**不要连续跳级**（H2 之后直接 H4 是错的）
- H3 数量控制在 5 个以内，多了说明结构该拆

### 段落
- 中文技术类推文：**段落 3-5 行为宜**，超过 8 行必须拆
- 不用连续空行分段（公众号里空行不美观），用空行隔开即可
- 每段第一句就说清这段在讲什么 —— 读者在手机上会扫读

### 代码块
- 必须标语言：` ```python ` 而不是 ` ``` `
- **超过 15 行的代码块要拆**，或者改成"要点 + 关键几行"
- 代码块前后各留一个空行，否则公众号渲染会粘连

### 强调
- 用 `**加粗**`，不要用 `*斜体*`（斜体在中文里可读性差）
- **一段里最多一处加粗**。全是重点等于没有重点

### 链接
- 关键链接给具名文本：`见 [官方文档](url)`，不要裸贴 URL
- 外链超过 3 个时，改为"参考资料"小节统一列出

## 检查清单

发布前逐条确认：

- [ ] 只有一个 H1
- [ ] 没有跳级标题
- [ ] 最长段落不超过 8 行
- [ ] 所有代码块都标了语言
- [ ] 没有超过 15 行的代码块
- [ ] 每段加粗不超过一处
- [ ] 没有裸 URL

## 调用排版工具

排版交给 MCP 工具，不要手写 HTML：

```python
result = render_markdown(markdown=text, platform="wechat")
html = result["html"]
warnings = result["warnings"]   # 超长截断等，务必检查
```

`warnings` 非空时**必须回头改内容**，不要靠工具截断了就发布。
