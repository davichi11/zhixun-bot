# 封面设计规范

## 唯一目标

> **读者在手机推送列表里，只有 0.3 秒扫过封面。**
> 这 0.3 秒里，标题必须能看清。

## 尺寸

- 公众号头图：**900 × 383**（2.35:1）
- 高清版：**1800 × 766**

## 标题怎么写

封面上的标题和文章标题**不要完全一样**。

| 用途 | 例子 |
|---|---|
| 文章标题 | "给 Agent 装上手：工具系统的四个必备件" |
| 封面文字 | "工具层怎么做才不出事" |

封面文字要**更短更狠** —— 它要在 40 个字以内讲清楚"这篇能给你什么"。

## 视觉规则

### 对比度是第一优先级
- 深底 + 浅字，或浅底 + 深字
- **禁止**：浅灰底 + 浅灰字（在小图上等于隐形）
- 文字与背景的对比度要足够在手机屏幕上阅读

### 字数
- **不超过 14 个汉字**，超了就删
- 字号要足够大：900px 宽的图上，正文至少 48px

### 一张图只讲一件事
- 不要在封面上堆三个概念
- 不要在封面上放代码片段
- 不要用密集的小字

## 风格一致性

同一账号的封面要能一眼认出是同一套：

- **固定配色**：全系列用同一组主色
- **固定版式**：标题位置、留白比例保持一致
- **固定字体**：不要一篇文章换字体

读者关注你的账号后，会形成"扫标题 + 认风格"的条件反射。破坏一致性等于放弃这个优势。

## 生成与检查

```python
result = generate_cover(title="工具层怎么做才不出事", width=900)
svg = result["svg"]
```

生成后**必须在手机上看一眼**：

- [ ] 把图缩到手机推送列表里的实际大小（约 300px 宽）
- [ ] 标题还看得清吗？
- [ ] 对比度够吗？
- [ ] 和上一期封面风格一致吗？
